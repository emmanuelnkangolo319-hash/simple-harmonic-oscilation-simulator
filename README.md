
# simple-harmonic-oscilation-simulator
A web app that allows you to graph functions and simple harmonic waves
This web app is tackling one of the problems with studying math, visualization. New features will be added, if you have any ideas worth mentioning, please comment and lets try getting into contact.

To run this just download the zip file, extract it, then open the extracted folder and double-click run_app.exe. The simulator opens instantly in your local browser. Its actually pretty quick and easy.

Features:
-Uses a selection box to take input from the user(the function they want to graph).
-Once the function is selected number inputs boxes pop up, the name and number of boxes depends on the function.
-Then it graphs the functions, ofcourse using you numbers for the calculations.
-With the simple harmonic waves function, it also shows you the frequency and angular frequency right on top of the graph.
*New features will be added, stuff like more mathematics topics, and way more physics.

I actually only used streamlit for this, since this project is not for super complicated. Ofcourse at some point i will probably integrate matplotlib and other quite "complicated" libraries, since this web-app will be evolving with me.
